# Notices and Dataset Attribution

This repository contains SQL scripts, documentation, and a Power BI report created for an independent analytics portfolio project.

The source data is the **Brazilian E-Commerce Public Dataset by Olist**, distributed through [Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce). The dataset is not included in this repository. Olist/Kaggle source attribution and the dataset's license terms remain applicable to the source data and any redistribution of data-derived material. Review the license and terms on the original dataset page before redistribution.

Unless explicitly stated otherwise, the project code and documentation are authored for this portfolio repository. No ownership of the original Olist dataset is claimed. A repository-level code license should not be interpreted as relicensing the third-party dataset or overriding its terms.
